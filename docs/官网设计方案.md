# ⚡️ pvfine 官方网站设计方案与技术规范 (v2.0 Cyber-Precision Edition)

本文档阐述 `pvfine` 官方宣传主页（`website/`）的视觉设计规范、交互式技术演示架构、全世代功能矩阵以及 GitHub Releases 自动解析机制。

---

## 🎯 1. 产品定位与核心视觉升级

`pvfine` 是一款面向某横版动作游戏 `Script.pvf` 归档文件的**现代化、高性能跨平台桌面编辑器与逆向解析套件**，基于 **Go 1.26 + Wails v3 + Vue 3 + CodeMirror 6** 构建。

v2.0 官网摒弃了传统静态模板与简易 Emoji 堆砌，采用 **Abyssal Cyber Dark（深渊赛博暗黑）与 Studio Light（高精密工程浅色）双主题架构**，融合多项现代原生 Web 技术：
- **交互式二进制星云背景（`#cyber-bg-canvas`）**：HTML5 Canvas 实时渲染 5 字节 PVF Token 流（`#PVF_File`、`sTrW::UTF-16LE`、`115CN-mod`、`MCP :19245`）与鼠标引力节点网络，后台标签页自动休眠零耗电。
- **CSS `@property` 旋转激光流光边框与聚光灯卡片（Spotlight Cards）**：基于鼠标坐标实时追踪的径向辉光（`--mouse-x` / `--mouse-y`）与可开关的 3D 视差悬浮桌面视窗。
- **View Transitions API & 原生 `<dialog>` 命令面板（`⌘K` / `Ctrl+K`）**：丝滑切换深浅主题与工作区标签页，支持全键盘快捷导航。

## 🖥️ 2. 六大在线交互式桌面工作台（Hero IDE Playground）

Hero 区域内嵌高保真拟真桌面客户端视窗，提供 **6 个可真实交互的在线子工作台**：

1. **`100300001.equ`（实时双向联动编辑器 + 粒子光环）**：
   - 点击工具栏即可动态切换装备品级（史诗 / 神话 / 太初）、强化三攻与全属强、就地改写 110US/115CN 译文。
   - 底部实时重算 **5 字节 Little-Endian 二进制 Token 流**（`02 7C 01 00 00`），右侧同步渲染装备属性面板与 Canvas 粒子环绕光环。
2. **`skill_slash.ani`（原生 Canvas 2D 帧动画与判定框引擎）**：
   - 60FPS 程序化渲染剑士拔刀斩关键帧序列、DXT5 Linear-Dodge 剑气弧光、暴击伤害跳字以及 `[hit box]` / `[damage box]` 实时碰撞判定框。
   - 支持播放/暂停、逐帧步进（`◀` / `▶`）、12 帧时间轴拖拽、倍速切换（`0.5x` / `1.0x` / `2.0x`）与图层开关。
3. **`swordman_tree.skl`（12+ 可视化 GUI 套件：技能树 + 商城/娃娃机）**：
   - 交互式切换技能节点、拖拽等级滑块（`Lv.1` ~ `Lv.40`）与全等级倍率叠加，实时重算 `[level info]` 静态/等级参数矩阵与模板占位符语义描述。
4. **`CompareWorkbench`（双栏归档对比与实时合并工作台）**：
   - 演示 `Script_115CN_Base.pvf` 与 `SeasonMod.pvf` 双栏差异比对，支持单段点击 `« 合入段落` 或 `⚡ 一键合入全部差异 (F7)` 并实时刷新脏块计数。
5. **`MCP AI Server (:19245)`（Streamable HTTP AI 终端）**：
   - 交互式演示 `pvf_annotation_explain`、内置掉率 Skill 预览（`pvf_script_preview`）与 `115CN-mod` 自动合并递增版本号导出（`pvf_mod_export`）。
6. **`batch_boost.pvf.js`（Goja 进程内 JS 沙箱）**：
   - 在线运行模拟 Goja 批处理脚本，毫秒级输出 Staging 事务隔离 Diff。

## 🔬 3. 在线 5 字节二进制 Token 反编译实验室（`#pipeline`）

页面内置实时 5 字节二进制 Token 编译器，支持点击预设或自由输入任意 PVF 语句（如 `[grade] 5`、`[physical attack] 2450`、`` `无影剑-艾雷诺` ``、`{8=<31::sword_epic>}`）：
- 实时将语句拆解为 `FF B0` 头部与 `0x05 Section`、`0x02 Int32`、`0x04 Float32 (IEEE-754)`、`0x07 String`、`0x08 StrRef` 5 字节小端序数据包。
- 实时计算 DJB2 `indexhash` 并展示 `sTrW` (UTF-16LE) 智能防乱码路由结果。

## 🔗 4. GitHub Release 自动解析与直链分发机制

1. **全平台智能识别**：通过 `navigator.userAgent` 与 `navigator.userAgentData` 自动识别 `macOS`、`Windows`、`Linux`，高亮推荐下载卡片并适配快捷键提示（`⌘K` / `Ctrl+K`）。
2. **GitHub API 异步拉取与缓存**：
   - 请求 `https://api.github.com/repos/dof-dev/pvfine/releases/latest`，配合 `sessionStorage` 10 分钟缓存避免触发 GitHub API 速率限制。
   - 自动提取最新 `tag_name`、发布日期、`body`（更新日志弹窗）与 `assets` 列表。
   - 自动匹配 `.github/workflows/release.yml` 发布的全部真实构建产物：
     - macOS：`pvfine-*-macos-universal.dmg` 与 `pvfine-*-darwin-universal-arm64-amd64.zip`
     - Windows：`pvfine-*-windows-amd64-installer.exe` 与 `pvfine-*-windows-amd64.exe`
     - Linux：`pvfine-*-linux-amd64.AppImage`
     - 校验码：`SHA256SUMS`
   - 所有下载按钮初始 `href` 均指向 `https://github.com/dof-dev/pvfine/releases/latest`，在离线或 API 受限时无损回退。
