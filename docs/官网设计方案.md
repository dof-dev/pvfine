# ⚡️ pvfine 官方网站设计方案与设计规范

本文档阐述 `pvfine` 项目官方宣传主页（Landing Page）的产品定位、视觉设计规范、信息架构规划、交互机制以及技术实现方案。

---

## 🎯 1. 产品定位与目标受众

### 1.1 产品定位
`pvfine` 是一款面向某横版动作游戏 `Script.pvf` 归档文件的**现代化、高性能跨平台桌面编辑器与解析套件**。基于 **Go 1.25 + Wails v3 + Vue 3 + CodeMirror 6** 技术栈构建。

官网定位为：**兼具专业硬核逆向工程质感与现代开发者体验（Developer Experience）的顶级开源工具官网**（参考 Linear、Raycast、Zed、Vercel 的审美范式）。

### 1.2 核心目标受众
- **游戏 MOD 创作者与脚本开发者**：需要高效、无乱码、结构清晰的代码编写与 LST 关联跳转体验。
- **逆向工程与算法探索者**：关注 110US (Paged110) 分页容器、AES-256-CBC 密钥链解密、90CN 变体种子推导及无损写回机制。
- **资源与资产维护者**：迫切需要免进游戏直接预览 ANI 关键帧动作、NPK/DXT 纹理与装备面板的高保真可视化能力。
- **Go 开发者与工具生态构建者**：关注 `internal/pvf` 纯 Go 模块的解耦调用与跨平台自动化集成能力。

## 🎨 2. 视觉设计系统（Design System）

### 2.1 视觉调性：双主题设计系统（Dual-Theme Architecture）
本官网支持深色（Dark Space）与浅色（Clean Minimalist Light）无缝平滑切换，默认自动适配系统偏好：

- **深色模式（Dark Space）**：
  - **底色基调**：深邃太空暗黑调（`#0a0c10` / `#12151d` / `#181b24`），配合低透明度发光网格与微蓝环境径向光晕。
  - **文本渐变**：白色到浅天蓝（`#ffffff` → `#60a5fa`），高光感强烈。
- **浅色模式（Clean Minimalist Light）**：
  - **底色基调**：清爽极简的 Slate 浅白灰（`#f8fafc`），纯白浮层卡片（`#ffffff`），浅灰分界线（`rgba(15, 23, 42, 0.08)`）。
  - **文本与对比度**：高对比度深蓝黑（`#0f172a` 与 `#475569`），主标题渐变采用深曜石黑到深海蓝（`#0f172a` → `#1d4ed8` → `#2563eb`），彻底杜绝白色文字在白底隐形的问题。
  - **客户端视窗浅色化**：标题栏与侧边栏融入浅灰（`#f1f5f9` / `#f8fafc`），代码区保持专业高对比暗色终端（`#0f172a`），右侧属性面板通透柔和。
  - **全页面协同适配**：对比表头、世代对比列、Bento 网格与页脚（`var(--bg-footer)`）全部自适应浅色，无任何黑白斑驳硬编码。

- **品牌强调色（双模式统一）**：
  - **电光荧光蓝（Electric Blue, `#4f8cff` / `#2563eb`）**：主品牌色与 CTA 交互高亮，代表极速流式解密与高性能内核。
  - **赛博薄荷绿（Cyber Emerald, `#34d399` / `#059669`）**：成功状态、逐字节一致性保障、无损写回。
  - **琥珀黄金（Amber Gold, `#fbbf24` / `#d97706`）**：高保真史诗装备、属性数值渲染与警告防护。
  - **霓虹紫（Neon Purple, `#a855f7` / `#7c3aed`）**：Goja JavaScript 沙箱与自动化脚本批处理。
  - **赛博青（Cyan, `#22d3ee` / `#0284c7`）**：Paged110 分页保护与 AES 密钥链反解。

### 2.2 材质与层次（Glassmorphism & Depth）
- **磨砂拟态**：多处采用 `backdrop-filter: blur(16px)` 半透明亚克力面板，与 macOS 原生窗口审美融为一体。
- **微流光微边框（Shimmer Border）**：细微高亮边框，悬停时触发平滑的辉光。
- **阴影深度**：多级阴影阶梯（`--shadow-sm` 到 `--shadow-lg`），提供悬浮层级立体感。

### 2.3 字体排印（Typography）
- **界面文本**：系统最佳现代无衬线字体栈（`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", sans-serif`）。
- **代码与数据**：专业的等宽编程字体（`"JetBrains Mono", "Fira Code", monospace`），确保 Token 缩进、密钥流十六进制与数值对齐严密。

### 3.1 拟真桌面视窗（Hero Interactive Simulator）
官网 Hero 区域内置了一个高保真模拟的 `pvfine` 客户端视窗，支持点击交互：
1. **`100300001.equ`**：展示 CodeMirror 6 代码高亮、层级感知缩进、LST 悬停 Tag 及右侧高保真史诗装备面板渲染（自动计算四维与技能）。
2. **`skill_slash.ani`**：展示内置 ANI 动作播放器（支持循环播放/暂停切换、关键帧序列与 DXT5 纹理图层调度）。
3. **`seria_shop.shp`**：展示结构化 GUI 商店视图（分类分页、商品卡片、成本与材料关联）。
4. **`batch_rarity.pvf.js`**：展示进程内集成 Goja 沙箱编写 JavaScript 批量改写归档与事务隔离 Diff 差异对比。

### 3.2 世代对比表（Comparison Matrix）
直观呈现传统老旧 MFC/WinForm 单平台工具在应对当今复杂归档时的局限性，对比凸显 `pvfine` 在 **启动速度、110US Paged 分页容器、90CN 变体恢复、UTF-16LE 智能防乱码、多媒体原生预览、JS 沙箱与全平台支持** 等方面的压倒性优势。

### 3.3 开发者生态（Pure Go SDK）
突出说明 `internal/pvf` 具备零 UI、零 Cgo 纯 Go 模块特性，提供极简的 6 行快速调用代码与复制功能。

### 3.4 GitHub Release 动态直链与版本加载机制
1. **统一降级保障**：所有下载按钮初始 href 均统一定位至 `https://github.com/dof-dev/pvfine/releases/latest`，离线或 API 受限时可安全回退。
2. **异步动态获取**：页面加载时通过 GitHub API（`/repos/dof-dev/pvfine/releases/latest`）异步拉取最新发布数据。
3. **版本与附件直链自动装配**：
   - 动态更新 Header 与 Hero 区域的版本指示标签（如 `v0.7.0`）。
   - 遍历 `assets` 附件列表，自动匹配各平台预编译安装包（如 `pvfine-*-macos-universal.dmg`、`windows-amd64-installer.exe`、`windows-amd64.exe`、`.AppImage` 等），将按钮链接直接提升为附件直链（`browser_download_url`），并动态标注文件体积（如 `22.8 MB`）。
   - 首页 Hero 主 CTA 下载按钮自动根据当前访客操作系统（macOS / Windows / Linux）直接绑定对应的安装包直链，实现一键直下。

## 🛠️ 4. 技术栈与目录结构

官网静态站点采用**现代轻量化原生技术方案**（Vanilla Modern Web），无须额外安装庞大复杂的编译构建流水线，双击即开、轻快敏捷：

```
website/
├── index.html       # 现代语义化 HTML5 骨架（Header/Hero/Bento/SDK/Download/Footer）
├── style.css        # 基于 CSS 变量的暗黑高质感设计系统与响应式适配
├── main.js          # 拟真视窗切换、UA 操作系统智能检测、代码复制、主题切换
└── assets/
    └── appicon.png  # pvfine 高清应用程序图标
```

### 本地预览与部署方式
1. **直接浏览器打开**：在访达/文件管理器中双击 `website/index.html` 即可完整体验。
2. **本地 HTTP 调试**：
   ```bash
   cd website && python3 -m http.server 8080
   # 打开 http://localhost:8080
   ```
3. **线上生产部署**：
   - 可直接配置 GitHub Actions 将 `website/` 目录发布至 GitHub Pages。
   - 或绑定至 Cloudflare Pages / Vercel，构建目录设置为 `website`，产物目录为根。
