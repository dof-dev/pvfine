### 批量查找/替换

- 全匹配查找替换
- 正则匹配替换

替换前预览 diff
比如：

查找：
[cool time]
    10000

替换：
[cool time]
    5000

最好结果页做成：

328 个文件命中 / 1267 处

☑ skill/a.stk
    - [cool time] 10000
    + [cool time] 5000

    - [cool time] 10000
    + [cool time] 5000
