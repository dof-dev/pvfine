# JavaScript 脚本工作区

脚本工作区使用 Goja 在进程内运行 `.pvf.js`。脚本只能操作当前打开归档的虚拟文件，运行阶段写入隔离事务；运行成功后生成预览，只有点击“应用选中”才会写入当前工作区 Overlay。应用后仍需通过归档编辑器的保存操作写回 PVF 文件。

## 最小示例

```js
for (const file of pvf.glob("equipment/**/*.equ")) {
  const document = file.parse();
  const price = document.section("price");
  if (price && price.get() < 10) {
    price.set(10);
    file.write(document);
  }
}
```

`sections(path)` 返回精确路径的全部 section；`section(path)` 和 `get/set/delete` 默认只访问第一个匹配项。重复 section 必须显式遍历 `sections()` 或传入 `occurrence`。替换已有值时保留原 token 类型；新增字符串默认是带引号字符串，新增数字按整数/浮点范围推断。

需要精确控制 token 类型时传入值对象：

```js
document.set("price", { type: "float", value: 3.5 });
section.set({ type: "quoted", value: "展示名", pool: "utf16" });
```

## 运行边界

- `file.parse()` 只接受 TypeScript 文件；`text()` / `setText()` 也支持 Unicode 文本文件。
- 结构化文档保留 token 顺序、类型和字符串池编码，不保留空白、注释或原始排版。
- 每次运行最多 5 分钟，同时只能有一个活动运行实例；停止、超时、归档切换和运行异常都会丢弃事务。
- Goja 沙箱不注册 `require`、`process`、`fetch`、Node.js 模块、本地文件、网络或 shell 能力。
- 脚本目录固定为 `os.UserConfigDir()/pvfine/scripts/`，只接受目录内 basename 格式的 `.pvf.js` 文件。

脚本服务事件：`script:state`、`script:log`、`script:progress`。
